混淆矩阵 : TN=211378  FP=59503  FN=52625  TP=318722，在验证的时候，这几个是什么意思

⏺ 在你的任务中，0=反质子（antiproton），1=反重氘核（antideuteron）：

  ┌────────────────────┬──────────────────┬────────────────────┐
  │                    │ 预测=0（反质子） │ 预测=1（反重氘核） │
  ├────────────────────┼──────────────────┼────────────────────┤
  │ 真实=0（反质子）   │ TN=211,378       │ FP=59,503          │
  ├────────────────────┼──────────────────┼────────────────────┤
  │ 真实=1（反重氘核） │ FN=52,625        │ TP=318,722         │
  └────────────────────┴──────────────────┴────────────────────┘

  - TN（True Negative）：真实是反质子，模型也判为反质子 → 正确
  - FP（False Positive）：真实是反质子，模型误判为反重氘核 → 假信号
  - FN（False Negative）：真实是反重氘核，模型漏判为反质子 → 漏检
  - TP（True Positive）：真实是反重氘核，模型也判为反重氘核 → 正确

  从这组数据看：
  - 准确率：(211378+318722) / 642228 ≈ 82.5%
  - FP=59503较高，说明有不少反质子被误判为反重氘核，这会降低Rejection power


混同行列（こんどうぎょうれつ）の説明：

  - TN（真陰性）：反陽子を正しく反陽子と判定 → 正解
  - FP（偽陽性）：反陽子を誤って反重陽子と判定 → 偽信号（最も抑制すべき）
  - FN（偽陰性）：反重陽子を見逃して反陽子と判定 → 信号損失
  - TP（真陽性）：反重陽子を正しく反重陽子と判定 → 正解

  要点：「FPが約6万件あり、反陽子背景の誤判定が多いため、CNN+DNNモデルのRejection
  powerは3.39に留まっています。GNNモデルではこのFPを大幅に低減し、Rejection power 12.1を達成しました。」
