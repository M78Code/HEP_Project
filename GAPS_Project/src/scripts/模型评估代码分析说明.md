# 模型评估代码（Evaluation）详细分析说明

## 1. 这段代码的核心作用

这段代码的作用并不是训练模型（Training），而是：

# 对已经训练完成的多个模型进行统一测试评估（Evaluation）

也就是对以下三个图神经网络模型进行性能比较：

* GIN（Graph Isomorphism Network）
* GravNet
* DGCNN（Dynamic Graph CNN）

主要目的是确定：

* 哪个模型的 antiD（反重氘核）识别能力最强
* 哪个模型的 antiP（反质子）背景抑制能力最高
* 哪个模型的 ROC 曲线表现最好
* 哪个模型最适合作为最终论文结果展示模型

这一部分在论文中通常属于：

# Experimental Results（实验结果）

章节，是整篇论文最重要的部分之一。

---

# 2. 整体流程（全局理解）

整个 Evaluation 流程如下：

```text
加载 test.pkl
        ↓
读取三个模型的 best.pth
        ↓
逐个模型做推理（Inference）
        ↓
计算各种评价指标
        ↓
输出混淆矩阵（Confusion Matrix）
        ↓
绘制 ROC 曲线
        ↓
绘制 Rejection Curve（HEP重点）
        ↓
保存图像用于论文/PPT
```

一句话总结：

# 比较三个 GNN 模型谁最强

# 5. 第三部分：run_inference()

这是整个 Evaluation 中：

# 最核心的部分

---

## （1）@torch.no_grad()

```python
@torch.no_grad()
```

表示：

# 关闭梯度计算

因为这里是：

# 测试（Inference）

而不是训练（Training）

所以：

* 更快
* 更省显存
* 更稳定

这是标准写法。

---

## （2）模型前向传播

```python
logits = model(batch.x, batch.edge_index, batch.batch)
```

输出：

```text
[batch_size, 2]
```

例如：

```text
[
 [2.1, 0.3],
 [0.1, 3.2]
]
```

表示：

模型对：

* antiP（类别0）
* antiD（类别1）

两个类别的打分。

注意：

这时候还不是概率，

而是：

# logits（原始分数）

---

## （3）softmax 转概率

```python
probs = torch.softmax(logits, dim=1)[:,1]
```

作用：

把 logits 转换为：

# 概率（Probability）

例如：

```text
[0.12, 0.88]
```

表示：

```text
antiD 的概率 = 88%
```

然后：

```python
[:,1]
```

只取：

# 类别1（antiD）

因为：

本研究的重点是：

# 找到 antiD

这非常符合 HEP 的实际需求。

# 6. 第四部分：print_metrics()

这里负责：

# 计算所有核心评价指标

也是论文中最重要的结果来源。

---

# 7. 为什么使用 threshold = 0.5

```python
preds = (probs >= 0.5)
```

意思是：

```text
如果 antiD 概率 ≥ 50%
就判断为 antiD
否则判断为 antiP
```

这叫：

# 分类阈值（Threshold）

默认：

```text
0.5
```

这是最常见的标准设置。

---

# 8. 各种评价指标解释（重点）

---

# ① Accuracy（准确率）

公式：

Accuracy = (TP + TN) / (TP + TN + FP + FN)

表示：

# 总体正确率

但是：

在 HEP 中它通常不够重要，

因为：

# 类别严重不平衡（Class Imbalance）

所以不能只看 Accuracy。

---

# ② Precision（精确率）

公式：

Precision = TP / (TP + FP)

表示：

```text
你预测为 antiD 的样本中
真正是 antiD 的比例
```

即：

# 纯度（Purity）

非常重要。

---

# ③ Recall（召回率）

公式：

Recall = TP / (TP + FN)

表示：

```text
真正存在的 antiD 中
你成功找回了多少
```

即：

# 信号效率（Signal Efficiency）

这是 HEP 中最重要的指标之一。

---

# ④ F1 Score

F1 Score 综合：

* Precision
* Recall

用于平衡：

# 纯度 和 效率

是非常有代表性的综合指标。

---

# ⑤ ROC AUC

表示：

# 模型整体分类能力

它不依赖：

```text
threshold = 0.5
```

因此比 Accuracy 更科学。

论文中一定会写。

---

# 9. 混淆矩阵（Confusion Matrix）

结构：

```text
TN FP
FN TP
```

含义如下：

| 项目 | 含义               |
| -- | ---------------- |
| TP | antiD 被正确识别      |
| TN | antiP 被正确拒绝      |
| FP | antiP 被误认为 antiD |
| FN | antiD 被漏掉        |

其中：

# FP（False Positive）

最危险。

因为：

它意味着：

# 背景污染信号

这在 HEP 中非常严重。

---

# 10. Background Rejection（背景抑制率）

代码：

```python
tn / (tn + fp)
```

表示：

# 背景抑制率

即：

```text
所有 antiP 中
成功拒绝了多少
```

例如：

```text
10000 个 antiP
正确拒绝了 9990 个
```

则：

```text
Rejection = 99.9%
```

在 HEP 中：

它甚至比 Accuracy 更重要。

因为真正目标是：

# 极强的背景抑制能力

这正是：

# GAPS 实验最核心的问题

---

# 11. plot_roc_curves()

作用：

绘制：

# ROC 曲线

横轴：

```text
False Positive Rate（FPR）
antiP误识别率
```

纵轴：

```text
True Positive Rate（TPR）
antiD信号效率
```

曲线越靠近：

# 左上角

表示模型越优秀。

这是论文中的标准图。

---

# 12. plot_rejection_curve()

这一部分：

# 非常非常重要

甚至比 ROC 更重要。

因为：

这是：

# HEP 标准图

而不是普通 AI 图。

---

横轴：

```text
Signal Efficiency
（antiD Recall）
```

纵轴：

```text
Background Rejection = 1 / FPR
```

即：

# 背景抑制倍数

例如：

```text
1000
```

表示：

```text
1000 个背景事件
只放过 1 个
```

这正是顶级 HEP 论文最重视的图。
