# 波形位置推定数据概览

## 数据基本信息

**来源**：大场同学卒业论文实验数据  
**物理系统**：闪烁体检出器（Scintillator Detector）  
**任务**：波形数据 → 粒子通过位置（cm）

---

## 文件命名规则

```
runNN_XX.dat

NN = 运行编号（Run Number）
     代表第几次实验运行
     
XX = 粒子位置标签（Position Label）
     粒子通过检出器的真实位置
     单位：cm
```

### **为什么这样命名？**

这是**监督学习数据**，需要：
- 输入：波形数据（特征）
- 标签：粒子位置（真值）

文件名本身就包含了标签信息，便于直接提取！

## 数据结构（单个`.dat`文件）

### 内容构成

```
run7_65.dat 包含：
│
├─ 事件1（Event 1）
│  ├─ Header信息（需要忽略）
│  │  ├─ Baseline
│  │  ├─ Amplitude  
│  │  ├─ Charge
│  │  └─ LeadingEdgeTime
│  │
│  └─ 波形数据（使用这个！）
│     ├─ CH0（左端闪烁体）：1024个样本
│     ├─ CH1（右端闪烁体）：1024个样本
│     ├─ CH2（触发信号）：1024个样本 ❌ 忽略
│     └─ CH3（触发信号）：1024个样本 ❌ 忽略
│
├─ 事件2（Event 2）
│  ├─ Header
│  └─ 波形数据
│
├─ 事件3（Event 3）
│  └─ ...
│
└─ 事件N
   └─ ...
```

### 物理含义

- **CH0 + CH1**：两端的闪烁体同时测量粒子信号
  - 位置越靠左 → CH0信号强，CH1弱
  - 位置越靠右 → CH0信号弱，CH1强
  - 通过两个信号的幅度比可以推断粒子位置

- **CH2 + CH3**：只用于触发，确认有粒子通过，不含位置信息

## 关键性质

### 1️⃣ 监督学习数据
✅ **标签来源**：文件名本身（`XX`部分）  
✅ **标签类型**：连续值（回归问题）  
✅ **标签范围**：15～140 cm

### 2️⃣ 多通道波形数据
✅ **通道数**：4个（CH0~CH3）  
✅ **有效通道**：CH0 + CH1（2个）  
✅ **样本率**：每通道1024个样本  
✅ **总特征量**：2通道 × 1024样本 = 2048维

### 3️⃣ 实验运行结构
✅ **多次运行**：15个不同运行（run7~run21）  
✅ **固定位置**：每次运行测试的位置是固定的（在文件名中）  
✅ **多事件**：每个run*.dat包含多个粒子事件

## 数据使用方式（DL视角）

### 数据加载流程

```
对于每个run*_XX.dat文件：

Step 1: 提取标签
        XX → float(label) = XX
             例如：run7_65.dat → label = 65.0

Step 2: 读取波形数据
        → CH0_waveform [1024]
        → CH1_waveform [1024]
        → 组合成 [2, 1024] 张量

Step 3: 配对输入输出
        Input:  [2, 1024] 波形张量
        Output: float(label) 位置标签
        
Step 4: 创建训练样本
        一个run*.dat可能包含N个事件
        → 产生N个(波形, 位置标签)配对
```

### 模型结构预期

```
Input Layer:
  Shape: [batch_size, 2, 1024]
  ↓
  (2个通道的1024样本波形)
  ↓
Feature Extraction (1D CNN / LSTM / Transformer)
  ↓
Dense Layers
  ↓
Output Layer:
  Shape: [batch_size, 1]
  (单个位置估计值，范围15~140 cm)
```
